# 🌪️ Pacific Hurricane Data Scraper – 1975 Season

This project is a **web scraping tool** built with **Python**, designed to extract and structure hurricane data from the **1975 Pacific hurricane season** page on **Wikipedia**.

Using **BeautifulSoup** and **regular expressions**, the scraper pulls details like hurricane names, dates, affected regions, and fatalities. The structured data is then cleaned and exported using **Pandas**.

---

## 📌 Features

- 🌐 Scrapes Wikipedia for 1975 Pacific hurricane season data
- 🧠 Extracts complex patterns using **regular expressions**
- 🧹 Cleans and formats the extracted data using **Pandas**
- 📄 Outputs structured hurricane records:  
  `Name`, `Date`, `Affected Areas`, `Fatalities`
